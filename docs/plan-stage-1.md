# Northstar. План этапа 1

Описание этапа: `docs/stage-1.md`. Каждый шаг написан так, чтобы его можно было сделать в новой сессии без памяти. Перед любым шагом прочитай `docs/stage-1.md`.

Обозначения: `[ ]` не начато, `[~]` в работе, `[x]` готово, `[!]` заблокировано. Владелец `human` значит, что шаг может сделать только Мэри (аккаунты, ключи, решения). Для каждого такого шага агент пишет подробную пошаговую инструкцию простыми словами, без терминов без объяснения.

## Основа

### 0.1 Создать приватный репозиторий на GitHub — [x]
Владелец: human
Do: агент даёт инструкцию, как создать пустой приватный репозиторий `northstar` на GitHub и подключить к нему папку проекта. Сам агент выполняет `git init` и привязку, когда Мэри пришлёт адрес репозитория.
Done-when: `git remote -v` показывает адрес, на GitHub репозиторий отмечен как Private.
Progress: готово 2026-11-18, репозиторий https://github.com/pingwisha/northstar (Private), создан агентом через gh, который уже вошёл в аккаунт pingwisha.

### 0.2 Каркас сайта — [x]
Владелец: agent
Do: создать `app/` на SvelteKit с TypeScript, Tailwind, адаптером Cloudflare, тестами (Vitest, Playwright). Файл `.gitignore` закрывает `.env`, `node_modules`, `.wrangler`.
Done-when: `npm run check`, `npm run test` и `npm run build` проходят.
Progress: готово 2026-11-18. Проверены check, unit-тест, build и один Playwright-тест (npx playwright test). Скрипт `npm run test` запускает unit и e2e вместе. Каркас взят из language-tracker без его уроков и словарей.

### 0.3 Cloudflare и вход через Google: что нужно от Мэри — [x]
Владелец: human
Do: агент пишет пошаговую инструкцию, как создать в Google Cloud ключ для входа (OAuth client, тип Web application) и как создать токен Cloudflare. Мэри кладёт значения в файл `.env`. Значения нигде не показываются в чате и не попадают в git.
Done-when: в `.env` заполнены нужные имена, `.env` не отслеживается git.
Progress: готово 2026-11-18. Ключ Google создан, значения в `.env`, токен Cloudflare взят тот же, что у language-tracker. Ключ ИИ (GEMINI_API_KEY) остаётся на шаг 1.3. Адрес для Google на сайте: https://northstar.pages.dev/auth/google/callback, поправить при публикации, если имя будет другим.

### 0.4 База данных — [ ]
Владелец: agent
Do: схема D1 в `migrations/`: пользователи, список приглашённых, цели, этапы, задачи, материалы, записи прогресса, сообщения чата.
Done-when: миграции применяются на пустой базе, тесты базы проходят.

### 0.5 Вход через Google и список приглашённых — [ ]
Владелец: agent
Do: вход через Google, доступ только тем, чья почта в списке приглашённых. Владелец добавляет людей на странице «Семья и доступ».
Done-when: тест доступа: чужая почта получает отказ, приглашённый видит только свои данные.

## Цели и прогресс

### 1.1 Расчёт прогресса — [ ]
Владелец: agent
Do: отдельный модуль по правилам из `docs/stage-1.md` (непроверенное равно нулю, вес задач, подпись «успеваешь или отстаёшь на N»).
Done-when: модульные тесты на все правила проходят.

### 1.2 Создание и список целей — [ ]
Владелец: agent
Do: страница «Мои цели»: добавить, изменить срок, завершить, карточка с кольцом и следующим шагом.
Done-when: сквозной тест создаёт цель и видит её в списке.

### 1.3 Ключ ИИ и серверный прокси — [ ]
Владелец: human, затем agent
Do: Мэри создаёт ключ ИИ по инструкции агента и кладёт в секреты Cloudflare. Агент пишет маленький Worker-прокси, ключ хранится только на сервере, доступ только у владельца.
Done-when: запрос из сайта получает ответ ИИ, в коде страницы ключа нет.

### 1.4 Файл правил ИИ — [ ]
Владелец: agent
Do: один файл с правилами (простой текст, без разметки, не выдумывать, дружелюбный, но требовательный тон). Менять его можно без переделки сайта.
Done-when: ответы ИИ проходят проверку на отсутствие символов `*`, `#`, скобок и косых черт.

### 1.5 Построение плана по цели — [ ]
Владелец: agent
Do: по цели и сроку ИИ создаёт этапы и задачи по дням с материалами. Если источник не найден, пишет «не знаю».
Done-when: для тестовой цели «сдать экзамен через 6 месяцев» создан план, все задачи уложены в срок.
