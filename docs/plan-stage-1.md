Описание этапа: `docs/stage-1.md`. Каждый шаг написан так, чтобы его можно было сделать в новой сессии без памяти. Перед любым шагом прочитай `docs/stage-1.md`.

Обозначения: `[ ]` не начато, `[~]` в работе, `[x]` готово, `[!]` заблокировано. Владелец `human` значит, что шаг может сделать только Мэри (аккаунты, ключи, решения). Для каждого такого шага агент пишет подробную пошаговую инструкцию простыми словами, без терминов без объяснения.

### 1.5 Построение плана по цели — [x]
Владелец: agent
Do: по цели и сроку ИИ создаёт этапы и задачи по дням с материалами. Если источник не найден, пишет «не знаю».
Done-when: для тестовой цели «сдать экзамен через 6 месяцев» создан план, все задачи уложены в срок.
Progress: готово 2026-11-18, 109 тестов логики и базы проходят. Браузерные тесты после этого шага не перезапускались: система остановила их из-за нехватки памяти, перезапустить по просьбе. Кнопка «Построить план» на карточке цели без плана (только владелец, ИИ пока только у него). Два прохода: сначала ИИ составляет этапы и задачи (до 60 задач, до 8 этапов), потом отдельным запросом на каждый этап подбираются материалы. Даты расставляет код, а не ИИ: задачи идут от сегодня до срока, тяжёлая задача занимает больше места, последний день остаётся запасным. Каждая ссылка от ИИ открывается; нерабочая заменяется подсказкой, где искать. Живая проверка «сдать ОГЭ по математике до 18.05.2027»: 7 этапов, 56 задач, у каждой есть материал, 11 рабочих ссылок, остальные подсказки, последняя задача 13.05.2027, 25 секунд и 8 запросов из 50 дневных. Замечено: многие ссылки ведут на главную страницу сайта (например oge.sdamgia.ru), а не на конкретную страницу. Это честно, но грубо; улучшить можно позже.

### 2.2 Кнопка «Я отстаю» — [x]
Владелец: agent
Do: пересчёт плана и объяснение, что изменилось.
Done-when: после пропуска дней задачи сдвигаются, а срок цели не нарушается.
Progress: готово 2026-11-18. Кнопка «Я отстаю: пересчитать план» на карточке цели, видна только когда цель отстаёт. Пересчёт делает код, а не ИИ (быстро, бесплатно, срок не может сдвинуться): несделанные задачи в прежнем порядке заново раскладываются от сегодня до срока, сделанные не трогаются, последний день остаётся запасным. Под кнопкой выводится объяснение: сколько задач сдвинуто, сколько было просрочено, на какую дату теперь последняя, сколько задач в день, и предупреждение, если больше 3 в день. На главной в блоке «Не сделано раньше» есть ссылка на страницу целей. Тесты: логика, база (чужие задачи не двигаются) и браузерный тест, всего 8 браузерных проходят. Нагрузка на память при запуске иногда валит первый запуск браузерных тестов, повтор проходит.
