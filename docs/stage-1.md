# Northstart. Этап 1

Northstart: личный проджект-менеджер для больших целей. Ты называешь цель и срок, сайт строит план по этапам и задачам на каждый день, подбирает материалы и честно показывает прогресс в процентах.

## Решения (согласованы 2026-11-17)

- Отдельный проект, папка `/home/mary/projects/northstar`.
- SvelteKit, Cloudflare Pages и D1, вход через Google. PIN-кодов нет.
- Доступ по приглашению. Открытая регистрация позже, отдельным этапом.
- ИИ только у владельца, через серверный прокси. Ключ ИИ не в коде страницы.
- GitHub: приватный репозиторий, публичным станет позже.
- Интерфейс только на русском.
- Сайт не только для владельца: его будут использовать и другие люди.

## Что изменилось после этапа 1 (на 2026-11-23)

Решения выше были верны на момент этапа 1. Сейчас действует другое, и сайт работает по нему:

- ИИ доступен всем, у каждого человека свой дневной лимит и есть общий лимит на всех участников.
- Регистрация открыта (с дневным лимитом новых аккаунтов), репозиторий на GitHub публичный.
- Публичные страницы (описание, конфиденциальность, условия) на русском и английском, внутри сайта русский.
- Название сайта Northstart. Адрес, папка, репозиторий и база по-прежнему называются northstar: это технические имена, они не видны людям.
- Актуальное описание поведения лежит в openspec/specs/.

## Что входит в этап 1

1. Вход через Google, список приглашённых.
2. Создание цели: название, срок, короткое описание.
3. План: ИИ разбивает цель на этапы и задачи по дням с учётом срока.
4. Материалы к задачам: статьи, видео, тренажёры, чек-листы. Если ИИ не уверен, он так и говорит и называет источник.
5. Главная «Сегодня»: кольцо общего прогресса, задачи на сегодня с галочками, ближайший дедлайн, статус «успеваешь или отстаёшь на N».
6. Список целей с карточками: срок, прогресс, следующий шаг.
7. Кнопка «Я отстаю»: план пересчитывается и объясняется, что изменилось.
8. Чат с ИИ, который знает цели и прогресс.

## Правила прогресса

- Задача: 0%, пока не отмечена; 100% после отметки.
- Этап: среднее по задачам с учётом веса.
- Цель: пройденные единицы делить на все, с весом.
- Общий прогресс: среднее по активным целям.
- Непроверенное равно нулю.
- Рядом с процентом всегда подпись «успеваешь или отстаёшь» и на сколько.

## Правила ИИ

- Простой текст, короткие абзацы, без звёздочек, решёток, скобок и косых черт.
- Дружелюбный, но требовательный. Без похвалы, пока нет результата.
- Не выдумывает факты и не придумывает задачи вне плана.
- Правила ИИ лежат в одном файле и меняются без переделки сайта.
- Никаких личных данных: паспорт, адрес, карты, чужие пароли.

## Дизайн

Спокойные цвета, много воздуха, крупное кольцо прогресса. Сначала телефон, потом компьютер. Светлая и тёмная темы. Крупные кнопки и читаемые шрифты.
