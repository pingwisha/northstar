# Northstar. План этапа 2

Описание: `docs/stage-2.md`. Перед любым шагом прочитай `docs/stage-1.md` и `docs/stage-2.md`. Обозначения те же, что в `docs/plan-stage-1.md`.

### 1.1 Ручные задачи — [ ]
Владелец: agent
Do: кнопка «Добавить задачу» (название, цель, день), изменить название, перенести на другой день, удалить. Доступно на «Сегодня» и в календаре. Процент пересчитывается сразу. Задача без цели не бывает. Вес по умолчанию 1.
Done-when: тесты: своя задача добавляется, меняется, переносится, удаляется; чужую тронуть нельзя; проценты правильные; браузерный тест на телефоне.

### 1.2 Свои материалы и заметки — [ ]
Владелец: agent
Do: к задаче добавить свою ссылку (только https) с названием и заметку. Свои материалы можно удалить, материалы ИИ нельзя менять. ИИ в чате видит свои материалы и заметки.
Done-when: тесты на проверку ссылки, на доступ и на то, что ИИ получает заметки; браузерный тест.

### 1.3 Тесты и пробные работы — [ ]
Владелец: agent
Do: записать результат пробника (дата, название, баллы из максимума, слабые темы), график роста, список слабых тем.
Done-when: тесты расчёта и доступа; график читается на телефоне.

### 1.4 Недельный отчёт — [ ]
Владелец: agent
Do: страница с итогом недели по цифрам сайта и короткий текст ИИ: что сделано, где отставание, что подтянуть. Только владелец, лимит ИИ тот же.
Done-when: отчёт не выдумывает цифр, все числа берутся из базы; тест.

### 1.5 Режим экзамена — [ ]
Владелец: agent
Do: обратный отсчёт, план последних недель, повторение слабых тем.
Done-when: тесты и проверка на телефоне.

### 1.6 Проверка Мэри — [ ]
Владелец: human
Do: Мэри неделю пользуется этапом 2 и пишет замечания.
Done-when: Мэри подтверждает, что этап 2 готов.
