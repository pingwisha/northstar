### 1.1 Ручные задачи — [x]
Владелец: agent
Do: кнопка «Добавить задачу» (название, цель, день), изменить название, перенести на другой день, удалить. Доступно на «Сегодня» и в календаре. Процент пересчитывается сразу. Задача без цели не бывает. Вес по умолчанию 1.
Done-when: тесты: своя задача добавляется, меняется, переносится, удаляется; чужую тронуть нельзя; проценты правильные; браузерный тест на телефоне.
Progress: готово 2026-11-19. Кнопка «Добавить задачу» на «Сегодня» и в календаре (на выбранный день): цель из списка, текст, день. Можно вставить список, по задаче на строку (до 30), маркеры и номера в начале строки убираются. Карандаш у задачи: переименовать, перенести на день, удалить (с вопросом «Удалить насовсем?»). День не раньше сегодняшнего и не позже срока цели; просроченную задачу можно переименовать, не двигая. Новая задача честно снижает процент, удаление пересчитывает. Чужие задачи и задачи завершённых целей менять нельзя. Действия общие для двух страниц: `app/src/lib/server/task-actions.ts`. 27 новых тестов, 15 браузерных проходят. Идеи из присланного ТЗ сохранены в `docs/ideas.md`.
