### Добавлено по просьбе Мэри (2026-11-20): свой часовой пояс у каждого
Пояс берётся из браузера и хранится в cookie `tz` (проверяется сервером, неизвестное имя заменяется на Белград). «Сегодня», календарь, просрочка, отчёт и ИИ считают день по поясу человека; отметка выполнения в отчёте тоже переводится в его пояс. Тесты: `goals.spec.ts` (пояса), `weekly.spec.ts`, браузерный `e2e/timezone.e2e.ts`. Браузерные тесты теперь идут по одному, а заполнение базы повторяется при занятой базе. Причина прежних «случайных» сбоев отчёта найдена: два теста использовали один номер цели.

### Подготовка к открытому доступу (2026-11-20, по просьбе Мэри: «сайт будет общедоступным»)
Сделано, сам вход для всех НЕ включён: по умолчанию сайт остаётся по приглашениям.
- Переключатель `SIGNUP`: если секрет равен `open`, любой подтверждённый Google-аккаунт входит как участник (владельцем не станет никто, кроме списка `ALLOWED_EMAILS`). Включить: `npx wrangler pages secret put SIGNUP --project-name northstar`, ввести `open`. Выключить: удалить секрет или записать `closed`.
- Страница «Мои данные» (`/account`): скачать всё одним файлом и удалить аккаунт со всеми данными (нужно написать УДАЛИТЬ). Старая сессия удалённого человека перестаёт работать.
- Страница «Конфиденциальность» (`/privacy`), открыта без входа; ссылки в подвале и на странице входа.
- Лимиты на человека: 3000 задач, 500 результатов пробников, 20 своих ссылок на задачу, 20 активных целей.
- ИИ остаётся только для владельца (чужие запросы не расходуют ключ).
- Не сделано: ограничение числа регистраций в день, защита от ботов, письмо-подтверждение, проверка юридических требований (политика, возраст, GDPR). См. ответ Мэри.
Тесты: `tests/account.test.ts` (7), браузерный `account.e2e.ts`.
