# Northstar. Идеи на потом

Источник: ранний черновик ТЗ, который Мэри прислала 2026-11-19 «на всякий случай». Тот черновик описывал сайт для одного человека с данными только в браузере. Northstar строится иначе (вход через Google, база D1, доступ по приглашению), поэтому архитектура берётся не оттуда. Ниже идеи из него, которые подходят Northstar. Решение о порядке принимает Мэри.

- Цвет и значок у каждой цели, категории целей, которые человек создаёт сам.
- Пауза и архив цели, вкладки «Активные» и «Архив».
- Учебные дни недели и минуты в день для цели: план раскладывается только по выбранным дням.
- Серия дней подряд.
- Кольцо «минуты за сегодня».
- Поздравление с конфетти на отметках 100, 50, 30, 14, 7, 3, 1 и 0 дней до срока (один раз на отметку), с уважением к настройке «уменьшить движение».
- Честный прогресс из трёх частей: план 40 процентов, качество проверок 40, регулярность 20; прогноз «успеваю, на грани, не успеваю» с порогами 110 и 90 процентов. Сейчас прогресс считается только по галочкам, это проще и тоже честно.
- Проверки после шага, тетрадь ошибок, пробные работы раз в 2-4 недели (совпадает с шагом 1.3 этапа 2).
- Недельный отчёт с кнопкой «Скопировать отчёт» и скачиванием PDF (совпадает с шагом 1.4 этапа 2).
- Быстрые команды в чате: «Объясни проще», «Дай план на неделю», «Проверь меня», «Отчёт за неделю».
- ИИ показывает предпросмотр изменения плана и ждёт подтверждения (пока план меняет только кнопка «Я отстаю»).
- Пометка под чатом: «ИИ может ошибаться, проверяй важное».
- Достижения, звёзды и уровни.
- Скачать все данные файлом и удалить всё.
- Настройки: размер текста, акцентный цвет, шрифт заголовков.
- Установка как приложение на телефон (PWA).
- Боковое меню на компьютере.
